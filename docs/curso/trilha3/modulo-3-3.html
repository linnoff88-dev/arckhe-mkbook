🖼️ Estudar os top 20 da categoria

Capa que destoa muito do nicho perde clique. Capa igual demais perde diferenciação. Equilibrar.

📋 Processo

  1. Busca sua categoria na Amazon
  2. Screenshot dos 20 mais vendidos
  3. Identifica padrões: cores, layout, tipografia
  4. Lista 3 elementos onde você vai SEGUIR (conformidade)
  5. Lista 1 elemento onde você vai QUEBRAR (diferenciação)
2

📐 Especificações KDP

Especs oficiais

  • Dimensões: 2560×1600 px (proporção 1.6)
  • Formato: JPG ou TIFF
  • Color profile: sRGB
  • Tamanho: <50MB
  • Mínimo: 1000px no lado maior

⚠️ Erros comuns

CMYK ao invés de sRGB → cores estranhas. Resolução <1000px → borrada no thumbnail. Proporção errada → KDP rejeita.

🤖 Capa com IA

Designer freelance: R$ 800-3000. Capa via IA + Canva: R$ 100, 1 dia.

1

Midjourney/DALL-E pro fundo

Gere 20-30 variações. Escolhe 3 candidatas.

2

Canva pra composição

Adiciona título + subtítulo + autor. Usa template de capa de livro.

3

Export 2560×1600 JPG sRGB

Canva tem preset de KDP eBook Cover. Usa.

4

🔠 Tipografia que vende

Regra: 1 fonte display pro título (bold), 1 fonte sans pro autor. Contraste >7:1.

💡 Thumbnail legibility

Título tem que ser legível no thumbnail de 100px. Reduz sua capa pra esse tamanho. Se não consegue ler título, refaz. Sem isso, ninguém clica.

5

📊 A/B test de capa

Sua opinião sobre "qual ficou melhor" é a pior. Voto de gente do nicho prediz vendas.

✓ Onde testar

  • PickFu (US$ 50 = 50 votos qualificados)
  • Grupo Facebook do nicho (grátis)
  • Story Instagram com poll
  • Lista de e-mail própria

✗ Onde NÃO testar

  • Família ("ficou linda" enviesado)
  • Designer profissional (opinião técnica ≠ comercial)
  • Comunidade genérica (sem alvo)
6

📕 Capa de paperback (se for imprimir)

Se vai imprimir via KDP Print, capa vira PDF wraparound: capa + lombada + contracapa com bleed.

📊 Calculadora oficial

KDP tem template calculator grátis que gera PDF base com dimensões exatas baseadas em: número de páginas, papel (white/cream), trim size. Sempre usa essa.
