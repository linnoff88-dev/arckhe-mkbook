📝 Conta KDP + W8-BEN

Sem W8-BEN, Amazon retém 30% de imposto na fonte. Com, retém 0% (treaty Brasil-EUA).

Passos

  1. Cria conta em kdp.amazon.com
  2. Tax Information → preenche W8-BEN
  3. EIN (você não precisa, brasileiro usa CPF como TIN)
  4. Banco que receba USD (Wise, Remessa Online, Nubank Global)

📊 Diferença real

$1.000 de royalty: com W8-BEN você recebe $1.000. Sem, recebe $700. Vale a hora de preenchimento.

2

🏷️ 3 categorias estratégicas

KDP deixa escolher 3 categorias. Estratégia: 2 nichos pequenos + 1 amplo.

Por quê

Bestseller em nicho pequeno ("Escrita Criativa > Não-ficção > Manuais") é fácil com 50 vendas. Vira badge "#1 New Release" que aumenta conversão em TODAS as categorias.

💡 Pesquisa de nicho

Use Publisher Rocket (US$ 97 one-time) ou pesquisa manual nas categorias da Amazon. Procura categoria com 50-500 livros (não 5.000).

3

🔑 7 keywords que tracionam

KDP aceita 7 keywords. Long-tail > head: "livro pra escrever em 30 dias" vence "livro" em volume útil.

✓ Long-tail (use)

  • "como escrever um livro em 30 dias"
  • "publicar ebook amazon kindle"
  • "escrita com IA para autores"

✗ Head (não use)

  • "livro"
  • "escrita"
  • "ebook"

📊 Onde pesquisar

Caixa de busca da Amazon — começa a digitar e ela completa com termos reais. Esses autocompletes são keywords-ouro.

4

📝 Descrição com HTML

KDP aceita HTML básico (h2, ul, strong, br). Layout estruturado converte 2-3x mais que bloco corrido.

<h2>Pra quem é esse livro</h2>
<p>Você é gerente de produto, acabou de virar pai/mãe...</p>

<h2>O que você vai aprender</h2>
<ul>
<li><strong>Sistema de volta</strong> — pós-licença posicionada</li>
<li><strong>30 primeiros dias</strong> — script de reentrada</li>
</ul>

💵 Preço estratégico

Sweet spots: $2.99 / $5.99 / $9.99. Royalty muda em cada faixa.

PreçoRoyaltyQuando usar
$2.9970%Lead magnet, lançamento agressivo
$5.9970%Mainstream — default
$9.9970%Premium / business / técnico denso
$14.99+35%Quase nunca — perde volume e margem
6

⏰ KDP Select sim ou não

Programa de exclusividade: 90 dias só na Amazon. Em troca: Kindle Unlimited + ferramentas de promoção.

✓ Vale quando

  • Primeiro livro (alavanca lançamento)
  • Audiência principal está na Amazon
  • Quer usar Kindle Unlimited pra royalty por página lida
  • Promo de "free download" pra escalar reviews

✗ NÃO vale quando

  • Autor estabelecido com lista grande
  • Vende mais via Kobo/Apple Books
  • Tem audiência internacional fora do KU
  • Quer flexibilidade de canal

✓ Resumo do módulo

✓
W8-BEN sempre — 0% imposto vs 30%
✓
2 nichos + 1 amplo — bestseller fácil em nicho
✓
Long-tail keywords — autocomplete Amazon
✓
Descrição com HTML — bullets convertem 2-3x
✓
Preço default $5.99 — 70% royalty + volume
✓
